# Motion Galaxy

Site of [Motion Galaxy](https://motion-galaxy.com): customizable templates for Final Cut Pro, sold on [FxFactory](https://fxfactory.com/search/?keywords=galaxy).

Static site: `index.html` + `img/`. No build step. Deployed to Hostinger (`public_html`) via Git.

Languages: English (default), Português, Español, Français, Deutsch, Italiano, 日本語.

## For future changes

- `CLAUDE.md` — instructions for Claude (structure, rules, deploy).
- `docs/HISTORICO-DO-PROJETO.md` — full project history, links, decisions and pending items (in Portuguese).
- `.claude/skills/motion-galaxy-web-design/` — design & motion skill used to build the site.
- `.htaccess` keeps `docs/`, `.claude/` and the `.md` files off the public website.
